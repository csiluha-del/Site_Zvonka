VOICE ROOM — голосовой звонок на двоих

ЗАПУСК
1. Установи Python 3.10 или новее с https://python.org (при установке включи Add Python to PATH).
2. Распакуй архив в отдельную папку.
3. Запусти START.bat.
4. Дождись ссылки вида https://....trycloudflare.com и отправь её другу.
5. Вы оба открываете ссылку, вводите одинаковое название комнаты (например 1234), свой логин и нажимаете «Подключиться».
6. Браузер запросит разрешение на микрофон. Разрешите его.
7. Для завершения нажмите «Покинуть звонок».

ВАЖНО
- Для микрофона на телефоне нужен HTTPS. START.bat автоматически скачивает Cloudflare Tunnel и выдаёт временную HTTPS-ссылку.
- Ссылка действует, пока открыто окно START.bat и работает сервер.
- Оба участника должны использовать одинаковый номер/название комнаты.
- Это минимальный голосовой звонок на двух участников, без чата и видеосвязи.
- Звук передаётся напрямую между браузерами через WebRTC; сервер используется для установления соединения.
- Если Windows Firewall спросит разрешение для Python, разреши доступ к частным сетям.
- Для стабильного соединения между разными сетями иногда может понадобиться TURN-сервер; в проекте настроены публичные STUN-серверы.
